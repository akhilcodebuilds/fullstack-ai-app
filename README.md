# 🤖 AI Smart Analysis Dashboard

A full-stack web application for sentiment analysis, interactive analytics, historical record management, and PDF report generation.

**GitHub Repository:** https://github.com/akhilcodebuilds/fullstack-ai-app

---

## 📌 Project Overview

The AI Smart Analysis Dashboard is a web-based application designed to analyze text sentiment and present analytical insights through an interactive dashboard.

The application integrates a React frontend, Flask REST API, and MongoDB database. Users can submit text for sentiment analysis, review previous analysis records, explore statistics and trends, and generate PDF reports.

## 🎯 Objectives

* Analyze user-provided text and identify its sentiment.
* Display sentiment analysis results through an interactive interface.
* Store and retrieve analysis records using MongoDB.
* Present analytical summaries and visualizations.
* Provide REST API endpoints for application functionality.
* Generate downloadable PDF reports.
* Demonstrate full-stack application development and API integration.

## ✨ Key Features

### 1. Sentiment Analysis

Accepts text input and displays the sentiment prediction generated by the backend.

### 2. Analysis History

Retrieves previously stored analysis records for review.

### 3. Analytics Dashboard

Displays available statistics and summaries of analyzed text.

### 4. Interactive Visualizations

Uses charts to present sentiment distribution and trend information.

### 5. PDF Report Generation

Provides an API endpoint for generating PDF reports.

### 6. Database Integration

Uses MongoDB to store and retrieve analysis records.

### 7. REST API Integration

Connects the frontend and backend through HTTP requests.

## 🔄 Application Workflow

1. The user enters text into the dashboard.
2. The frontend sends an HTTP request to the Flask backend.
3. The backend processes the request and generates a sentiment result.
4. Analysis records are stored in MongoDB according to the implemented backend logic.
5. The frontend displays the result.
6. Users can view available history, statistics, and trends.
7. Users can request a PDF report through the report API.

## 🔌 REST API Endpoints

The application provides the following endpoints.

| HTTP Method | Endpoint          | Description                           |
| ----------- | ----------------- | ------------------------------------- |
| GET         | `/api/health`     | Checks backend availability           |
| POST        | `/api/sentiment`  | Processes sentiment analysis requests |
| GET         | `/api/history`    | Retrieves analysis history            |
| GET         | `/api/stats`      | Retrieves analytical statistics       |
| GET         | `/api/trends`     | Retrieves trend information           |
| GET         | `/api/report/pdf` | Generates a PDF report                |

The API response format and accepted request fields depend on the backend implementation.

## ⚙️ Installation and Setup

### Prerequisites

Install the following tools:

* Python
* Node.js and npm
* MongoDB
* Git
* Visual Studio Code (recommended)
* Postman (for API testing)

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/akhilcodebuilds/fullstack-ai-app.git
cd fullstack-ai-app
```

### 2. Set Up the Python Environment

From the project root, create a virtual environment if one does not already exist:

```powershell
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the backend dependencies using the dependency file provided by the project.

For example, if `backend/requirements.txt` exists:

```powershell
pip install -r backend/requirements.txt
```

If your dependency file is stored elsewhere, use its actual path.

### 3. Start the Backend

Follow the backend configuration and start the Flask application.

If the application supports being started from the project root, the command may be:

```powershell
python backend/app.py
```

Otherwise, use the startup command appropriate to the actual backend configuration.

The backend is expected to use `http://127.0.0.1:5000` if configured with that address.

### 4. Set Up the Frontend

Open a second terminal in VS Code.

Navigate to the frontend directory:

```powershell
cd frontend
```

Install dependencies:

```powershell
npm install
```

Start the development server:

```powershell
npm run dev
```

Open the local URL displayed in the terminal. With the default Vite configuration, it is commonly:

```text
http://localhost:5173
```

### 5. Configure MongoDB

Ensure MongoDB is running and the backend has the correct database connection settings.

Keep database credentials and connection strings in environment variables or an appropriate local configuration file. Do not publish passwords or secrets to GitHub.
